Un comportement en quelques lignes

Le carré vert du Sandbox tourne grâce à ce comportement. Il est attaché à une entité via le composant Script ; le ScriptSystem appelle onUpdate à chaque frame.

Guide des comportementsRéférence des composants
behaviors/rotating.hC++
class Rotation : public IBehavior {
    void onUpdate(Entity self, Registry& registry, float dt) override
    {
        auto& t = registry.getComponent<Transform2D>(self);
        float rotationSpeed = 45.0f;
        t.setRotation(t.getRotation() + sf::degrees(rotationSpeed * dt));
    }
};
