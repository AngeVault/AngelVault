Points d'attention repérés dans le code

Constats faits dans la copie locale du dépôt. #4 (« traiter les points d'attention ») est terminée : certains de ces points sont peut-être déjà corrigés.

#OùConstatPisteLien
1Game::init()m_systems.start() n'est appelé qu'à la construction : les systèmes ajoutés ensuite (Physics, Collision, Script…) ne reçoivent jamais onStart.Appeler onStart dans addSystem si le jeu est déjà démarré, ou exposer un game.start() après le chargement de la scène.#24
2SystemManagerstd::sort n'est pas stable : l'ordre de deux systèmes de même priorité n'est pas garanti.Utiliser std::stable_sort.#24
3ScriptSystemonDestroy n'est appelé qu'à l'arrêt du jeu, pas à la destruction d'une entité isolée.Brancher Registry::onDestroy<Script> pour appeler onDestroy.—
4Game / LooseFileLoaderLe chargeur est construit avec son chemin par défaut games/rts/assets/resources.txt, hérité du prototype RTS. Sans ce fichier, les identifiants de texture sont traités comme des chemins directs.Passer un chemin explicite, ou attendre le module assets.#38
5engine/ai/CMakeLists.txtContient av_module(Core …) : le nom devrait être AI (sans effet tant que le dossier n'est pas ajouté à engine/CMakeLists.txt).Renommer avant d'activer le module.#45
6CameraSystem / rpg_scene.hLe CameraSystem lit encore sf::Keyboard (flèches, +, −) alors que le RPG déclare les actions Zoom, ZoomWheel, CameraX et CameraY : elles ne servent à rien pour l'instant. Les champs panSpeedGamepad et zoomLerpSpeed ne sont pas lus non plus.Faire lire les actions par le système (le module Render2D dépend déjà d'Input) et brancher le lissage du zoom.#25
7render_system.hUne fonction inline void test(Camera2d&) vide traîne en bas du fichier.La supprimer.—
8Intégration continueLe dossier .github/ est vide dans la copie lue : aucun build ni test automatique.Ajouter un workflow qui lance le preset x64-debug-no-editor puis ctest.#1
9loadRpgInputLe chemin assets/input.cfg est relatif au dossier de lancement : lancé depuis un autre dossier, rpg.exe retombe sans bruit sur les actions par défaut du code.Résoudre le chemin depuis l'exécutable, ou afficher un avertissement dans la console.#38
10TestsSeuls ComponentPool et les outils de maths (test_math) sont testés.Ajouter des tests pour Registry::view, la destruction différée, les collisions et l'InputManager (lecture de input.cfg).#55
