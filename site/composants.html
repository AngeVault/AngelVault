Référence des composants

Tous les composants du moteur, avec leurs champs et leurs valeurs par défaut, tels qu'ils sont dans le code.

Les composants sont de simples structures. On les ajoute avec registry.addComponent<T>(entité, …) et on les lit avec getComponent<T>. Les valeurs par défaut ci-dessous sont celles du code.

Core

Transform2D core/components/transform2d.h

Position, rotation et échelle d'une entité 2D. Les champs sont privés : on passe par les accesseurs, qui marquent la matrice locale comme à recalculer.

MembreTypeDéfautDescription
depthfloat0Profondeur (public)
setPosition / getPositionsf::Vector2f{0, 0}Position dans le monde
setRotation / getRotationsf::Angle0°Rotation (utilisez sf::degrees(…))
setScale / getScalesf::Vector2f{1, 1}Échelle
move(offset) / rotate(angle)——Ajoute à la position / à la rotation
getLocalMatrix()const sf::Transform&—Matrice translation·rotation·échelle, recalculée seulement si nécessaire

Transform3D core/components/transform3d.h

ChampTypeDéfaut
positionglm::vec3(0, 0, 0)
rotationglm::quatidentité
scaleglm::vec3(1, 1, 1)

getModelMatrix() renvoie la matrice 4×4 translation · rotation · échelle.

NameComponent core/components/name.h

Un seul champ, std::string name, construit via NameComponent("Player"). Sert à l'affichage dans la Hierarchy ; il est réfléchi pour l'éditeur (reflectComponent<NameComponent>).

Script core/components/script_component.h

ChampTypeDescription
behaviorstd::unique_ptr<IBehavior>Le comportement porté
startedbool (false)Passe à vrai après l'appel de onStart

Non copiable, déplaçable. Voir Comportements C++.

ChampTypeDéfautDescription

Méthodes : applyForce(f) (accumule), applyImpulse(i) (velocity += i / mass), applyTorque(t), inverseMass() et inverseInertia(). Les corps statiques ignorent forces et impulsions.

Camera2d render2d/components/camera2d.h

Une caméra est une entité : sa position est celle de son Transform2D. Le composant ne contient que les réglages ; c'est le CameraSystem qui construit la sf::View (voir Render2D).

ChampDéfautDescription
zoom / targetZoom1Zoom courant et zoom visé (en caméra libre, zoom prend targetZoom à chaque frame)
minZoom / maxZoom0.25 / 4Bornes du zoom ; avec des bornes de monde, minZoom est recalculé pour que la vue tienne dans la carte
targetLockNULL_ENTITYEntité suivie. Valide : la caméra se place sur elle ; sinon la caméra est libre (flèches, +, −)
panSpeedKeyboard1000Vitesse de déplacement au clavier (multipliée par le zoom)
panSpeedGamepad100Vitesse à la manette (pas encore utilisée)
zoomStep0.5Pas de zoom par seconde
zoomLerpSpeed12Lissage du zoom (pas encore utilisé)
worldMin / worldMax{0, 0}Limites du monde (inactives si max ≤ min)

Méthodes : setWorldBorder(min, max) et setTarget(entité). Les huit champs numériques sont exposés à l'Inspector par reflectComponent<Camera2d>.

usageC++
auto& camera = registry.addComponent<Camera2d>(cameraEntity);
camera.setWorldBorder({ 0.f, 0.f }, { 3000.f, 3000.f });
camera.setTarget(player);   // la caméra suit le joueur

SpriteComponent render2d/components/sprite_component.h

Enveloppe un sf::Sprite et un layer. Les scènes actuelles utilisent plutôt Geometry::SpriteData.
