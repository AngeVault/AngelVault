Un comportement en quelques lignes

Cette classe fait tourner une entité. La ligne REGISTER_BEHAVIOR la déclare : elle apparaît dans l'Inspector de l'éditeur, ses réglages PROPERTY sont enregistrés dans la scène, et le ScriptSystem appelle onUpdate à chaque frame.

Code de jeuGuide des comportements
behaviors/rotating.hC++
class Rotation : public IBehavior {
public:
    PROPERTY(float, degreesPerSecond, 45.f)   // réglable dans l'Inspector

    void onUpdate(Entity self, Registry& registry, float dt) override
    {
        auto& t = registry.getComponent<Transform2D>(self);
        t.setRotation(t.getRotation() + sf::degrees(degreesPerSecond * dt));
    }
};
REGISTER_BEHAVIOR(Rotation)                  // visible dans l'éditeur et les scènes
